# AIHOT: 概要

KKKKhazix/AIHOT は 2026-09-29 に GitHub で作成されたリポジトリです。2026-10-16 時点のスター数は 7,887 です。

- 自分でホットトピックを探して日報を書く、ウェブサイトのフレームワークです。
  - 原文（README）: 一个自己找热点、自己写日报的网站框架。
- 毎日、複数の情報源から資料を集め、大規模モデルで一度ふるいにかけてから 2 回独立に採点し、中国語の見出しと要約を書きます。同じ出来事を報じる記事は 1 つのイベントにまとめ、日報を毎朝出します。
  - 原文（README）: 它每天从一批信源里收资料,用大模型先筛一遍、再独立打两次分,挑出真正值得看的,写成中文标题和摘要;把不同来源说的同一件事聚成一个事件,按有多少人在说排出热点;每天早上出一份日报。
- このリポジトリには、ウェブサイト、管理画面、精選の流れ、クラスタリングと熱度の計算方法、すべてのプロンプトの原文と採用の基準が含まれています。
  - 原文（README）: 这个仓库是它的引擎和框架:网站、后台、精选流程、聚簇和热度算法,所有提示词的原文和入选门槛,都在这里。

## 主な機能と構成（README の要約）

- 情報源から入った資料は、重複の判定と事前の選別を経て、重要そうなものは 2 回独立に採点され、中国語の見出しと要約を付けて他の報道とイベントにまとめられ、熱度に加算されます。
  - 原文（README）: 一条资料从信源进来,先判重,再预筛;可能重要的独立打两次分,写好中文标题和摘要,和别的报道聚成事件,算进热度。
- 各ステップのプロンプトは industry/prompts/ にあり、基準を変えるのにコードを変える必要はありません。
  - 原文（README）: 每一步的提示词都在 industry/prompts/,改标准不用改代码。
- 熱度は記事ではなくイベント単位で数え、48 時間以内は独立した情報源ごとに 1 回だけ数え、24 時間で半減します。
  - 原文（README）: 热度按事件算,不按文章算:48 小时内,每个独立来源只算一次,24 小时减半。
- 情報源は、RSS、ウェブページの一覧、JSON インターフェース、X のアカウント、微信公式アカウント、自作スクリプトから送り込む内容の 6 種類です。
  - 原文（README）: 六种信源 / RSS、网页列表、JSON 接口、X 账号、微信公众号,以及你自己脚本推送进来的内容。
- エージェント向けに RSS（精選・全件・全文・日報・週報・月報）、公開 API、MCP、Agent Markdown、llms.txt を用意し、同じ内容を人もエージェントも使えます。
  - 原文（README）: 给 Agent 用 / RSS(精选、全部、全文、日报、周报、月报)、公开 API、MCP、Agent Markdown、llms.txt,同一份内容给人看也给 Agent 用
