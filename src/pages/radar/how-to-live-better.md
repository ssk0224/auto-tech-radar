# how-to-live-better: 概要

cdyforever/how-to-live-better は 2026-09-18 に GitHub で作成されたリポジトリです。2026-10-11 時点のスター数は 10,927 です。

- オープンソースの書籍『高性价比人生指南』の 32 節・528 項目の助言を、検索できる 1 つの HTML の閲覧ページにまとめたものです。
  - 原文（README）: 一个单文件 HTML 阅读页,把开源书《高性价比人生指南》的全部 32 节、528 条建议 渲染成可搜索的页面。
- スマートフォンで開けばそのまま読め、何もインストールする必要はありません。
  - 原文（README）: 手机上打开就能看,不用装任何东西。
- このリポジトリは原書の fork ではなく、原書の内容も変えません。
  - 原文（README）: 本仓库不是原书的 fork,也不改动原书内容。

## 主な機能と構成（README の要約）

- 外部のリソースは使わず、CDN もフォントの外部リンクもなく、データを fetch しないため、オフラインでも読めます。
  - 原文（README）: 零外部资源:没有 CDN、没有字体外链、不 fetch 任何数据,断网也能读
- サイト全体のキーワード検索（結果を強調表示）と、A 級だけ・「说人话」だけの絞り込みができます。
  - 原文（README）: 全站关键词搜索(结果高亮)、只看 A 级、只看说人话
- ビルドは不要で、index.html をダブルクリックするだけで開けます。
  - 原文（README）: 不用构建,双击 index.html 即可。
- .github/workflows/rebuild.yml が毎日 06:00（北京時間）に上流を取り込んで作り直し、内容に変化があったときだけコミットします。
  - 原文（README）: .github/workflows/rebuild.yml 每天 06:00(北京时间)拉取上游重新生成, 内容有变化才提交。
