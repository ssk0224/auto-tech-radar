# answer-me-with-html: 概要と革新性

LLMやAIエージェントが高度化するにつれ、開発現場では「出力される膨大なテキスト（Wall of Text）の認知的負荷」が最大のボトルネックになりつつあります。Andrej Karpathy氏が指摘したように、LLMの自律性が高まるほど、その出力を人間がいかに高速に咀嚼できるかが重要になります。

**`answer-me-with-html`** は、Claude Code、Cursor、Codex、OpenCodeといった各種AIエージェントに組み込むオープンソースの「エージェント・スキル（Agent Skill）」です。複雑なアーキテクチャの質問、TCPのハンドシェイク、DBの比較検討などを尋ねた際、端末画面を埋め尽くす長文テキストではなく、シーケンス図、フローチャート、状態遷移表、比較マトリクスが美しくレイアウトされた**完全スタンドアロンの1枚のHTMLファイル**を瞬時に生成・表示します。

### 本ツールの革新的なコアメカニズム
従来、LLMに「HTMLで出力して」と指示した場合、数千行におよぶインラインCSSやSVGの座標計算を出力させることになり、以下のような深刻な問題が生じていました：
1. **生成待ち時間が極めて長い**（30秒〜1分以上）
2. **トークン消費量が膨大**（出力トークン枯渇やコスト高騰）
3. **SVG図解の崩壊**（LLMは座標計算が苦手なため、矢印があらぬ方向を指す）

`answer-me-with-html` はこの責務を完全に分離しました。
- **LLMの役割**: わずか600トークン前後の専用Markdownドラフト（データ構造とテキストのみ）を書くだけ。
- **バンドルCLIの役割**: レイアウト計算、カラーパレット適用、`dagre` によるグラフ自動配置、SVG描画、ASD-STE100準拠の構文チェックをローカル（約50ms）で実行。

結果として、**出力トークン数は手書きHTML比で約1/8（87%減）、生成完了速度は2.6倍**に高速化されます。

## 解決する主要な課題とアーキテクチャ

### 1. 解決する課題
- **認知的オーバーロード**: 端末上のモノスペースフォントによる長文ログを読む苦痛の解消。
- **LLMのトークン生成オーバーヘッド**: CSS/SVGタグ出力によるAPIレイテンシと課金増の抑制。
- **外部依存とセキュリティ**: 外部SaaSやCDNに依存せず、完全ローカルかつ単一の自己完結HTMLファイルで閲覧・共有可能。

### 2. システムアーキテクチャ
本ツールはランタイムに Node.js（20以上）のみを要求し、外部CDNや追加のnpmインストールを必要としません（`marked` や `@dagrejs/dagre` などの必要ライブラリは `am.mjs` に事前バンドル済み）。

```
+-------------------------------------------------------+
|  User / Terminal (Claude Code, Cursor, Codex, etc.)  |
+-------------------------------------------------------+
                           |  質問入力 (e.g. "Explain TCP handshake")
                           v
+-------------------------------------------------------+
|  LLM Agent (Markdown Draft生成のみ担当: ~600 tokens)  |
|  - frontmatter (メタデータ)                            |
|  - ```sequence, ```flow, ```er, ```tree 等の構文       |
+-------------------------------------------------------+
                           |  CLIパイプ渡し (< 50ms)
                           v
+-------------------------------------------------------+
|  answer-me-with-html CLI (am.mjs)                     |
|  - Dagre Layout Engine (SVG/座標自動算出)             |
|  - Theme Engine (blueprint / shadcn / paper)          |
|  - ASD-STE100 Rule Checker (平易な表現の検証)        |
+-------------------------------------------------------+
                           |
                           v
+-------------------------------------------------------+
|  Output: Single File HTML (~/.answer-me-with-html/)   |
|  - 完全オフライン動作 / CSS/JS/SVG埋め込み済み        |
|  - インタラクティブ機能（フィードバック・選択肢返信） |
+-------------------------------------------------------+
```

### 3. 主なサポートコンポーネント
- `flow`: アーキテクチャ図、決定分岐、コールグラフの自動階層レイアウト
- `sequence`: メッセージの時系列シーケンス図
- `er`: 主キー・外部キーおよび多重度（Crow's foot記法）対応のER図
- `timeline` / `tree`: 歴史的経緯やリポジトリのディレクトリ構造
- `ask`: HTML上でユーザーが選択肢をクリックしてエージェントに逆フィードバックできるフォーム
- `video`: 3Blue1Brownスタイルの音声ナレーション付き解説動画（WebM/MP4）自動生成

- **マネタイズ**: 大手SIerやエンタープライズ企業向けの開発プロセス高速化コンサルティングおよび環境構築（1案件あたり80万〜150万円の導入支援費用）。

### 3. テクニカルセールス・提案書向け「3b1b風 解説動画」自動生成サービス

- **マネタイズ**: 開発者向けSaaS企業への「ドキュメント動画化代行・自動化基盤」としての月額提供。

## インストール & クイックスタート手順

### 前提条件
- Node.js 20.0.0 以上

### 1. エージェントへの自動インストール（推奨）
Claude Code、Cursor、Codex等を開き、以下のプロンプトを入力するだけで完了します。
```text
Install Answer me with HTML: read https://raw.githubusercontent.com/QingYunA/answer-me-with-html/main/INSTALL.md and follow it.
```

### 2. Claude Codeプラグイン経由でのインストール
Claude Codeのプロンプト上で直接実行：
```bash
/plugin marketplace add QingYunA/answer-me-with-html
/plugin install answer-me-with-html@answer-me-with-html
```

### 3. CLIワンライナーでの導入（Vercel Skills連携）
```bash
npx skills add QingYunA/answer-me-with-html
```

### 4. 実際の利用方法
通常通りエージェントに質問するだけで、自動判定または指定によってHTMLが生成されます。
```bash
> Explain the TCP three-way handshake
> Map out how the modules in this repo fit together
> Redis or Memcached for our cache?
```
生成されたファイルは `~/.answer-me-with-html/pages/` に自動保存され、デフォルトでブラウザが立ち上がります。
