## はじめに：なぜ今、世界中で爆発的に注目されているのか？

GitHubで瞬く間にスター数15,000件を突破し、クリエイティブ業界とエンジニアコミュニティの双方で話題をさらっているSwift製OSS「**Compositor**」。
一言で言えば、「**Photoshopの代替となるApple Siliconネイティブな高機能画像編集環境であり、外部スクリプトやAIエージェントからリアルタイムに操作できるオープンソース**」です。

これまで、企業のクリエイティブ制作現場では以下のような深刻なペインが存在していました：
- **Adobe CCの莫大なライセンス費**: 1シートあたり年間数万〜十数万円。数百人規模の制作会社や事業会社では年間数千万円規模の固定費負担。

- **価格設定**:

- **強み**: クラウドに画像データをアップロードしないため、未公開商品や機密情報を扱う大手ブランドがセキュリティ審査なしで即時導入可能。

## 商用カスタマイズ・実装の勘所（コピペで使える設計ガイド）

Compositorのコアは、`.comp`ファイル（実体はディレクトリ）内のマニフェストファイルと画像アセットの整合性にあります。以下は、Pythonから完全にCompositorプロジェクトを動的に組み立て、Compositorでリアルタイムに開くための実用スクリプトです。

### 1. `.comp` プロジェクト自動生成 Python スクリプト (`build_project.py`)

```python
#!/usr/bin/env python3
import json
import os
import shutil
from pathlib import Path
from PIL import Image, ImageDraw, ImageFont

def create_compositor_project(output_path: str, width: int = 1200, height: int = 630):
    """
    Compositorがリアルタイム読み込み可能な .comp ディレクトリを生成する
    """
    project_dir = Path(output_path)
    if project_dir.exists():
        shutil.rmtree(project_dir)
    project_dir.mkdir(parents=True, exist_ok=True)

    # 1. 背景レイヤー画像の作成
    bg_img = Image.new("RGBA", (width, height), (26, 32, 44, 255))
    bg_path = project_dir / "layer_background.png"
    bg_img.save(bg_path, "PNG")

    # 2. アクセントグラフィック（カード背景）の作成
    card_img = Image.new("RGBA", (width - 100, height - 100), (45, 55, 72, 230))
    card_path = project_dir / "layer_card.png"
    card_img.save(card_path, "PNG")

    # 3. Compositorマニフェスト (manifest.json) の構築
    manifest = {
        "version": 1,
        "canvas": {
            "width": width,
            "height": height,
            "resolution": 72
        },
        "layers": [
            {
                "id": "layer-bg-01",
                "name": "Background Color",
                "type": "raster",
                "file": "layer_background.png",
                "visible": True,
                "opacity": 1.0,
                "blendMode": "normal",
                "transform": {
                    "x": 0,
                    "y": 0,
                    "scaleX": 1.0,
                    "scaleY": 1.0,
                    "rotation": 0
                }
            },
            {
                "id": "layer-card-02",
                "name": "Content Card",
                "type": "raster",
                "file": "layer_card.png",
                "visible": True,
                "opacity": 0.95,
                "blendMode": "normal",
                "transform": {
                    "x": 50,
                    "y": 50,
                    "scaleX": 1.0,
                    "scaleY": 1.0,
                    "rotation": 0
                },
                "effects": {
                    "dropShadow": {
                        "enabled": True,
                        "color": "#00000088",
                        "blur": 20,
                        "offsetX": 0,
                        "offsetY": 10
                    }
                }
            },
            {
                "id": "layer-text-03",
                "name": "Catchcopy Text",
                "type": "text",
                "visible": True,
                "opacity": 1.0,
                "text": "Compositor AI Pipeline Ready",
                "fontFamily": "Helvetica Neue",
                "fontSize": 48,
                "fillColor": "#FFFFFF",
                "transform": {
                    "x": 100,
                    "y": 150
                }
            }
        ]
    }

    manifest_path = project_dir / "manifest.json"
    with open(manifest_path, "w", encoding="utf-8") as f:
        json.dump(manifest, f, indent=2, ensure_ascii=False)

    print(f"✅ Compositorプロジェクトが正常に生成されました: {project_dir}")

if __name__ == "__main__":
    create_compositor_project("./MarketingBanner.comp")
```

### 2. 実行とCompositorでの確認
```bash
python3 build_project.py
open -a Compositor MarketingBanner.comp
```
このスクリプトを実行した状態で、バックグラウンドのPython側で`manifest.json`の`x`座標や`fillColor`、あるいは`layer_card.png`を書き換えると、起動中のCompositor上で即座に描画が同期されます。

### 3. 社内運用時のセキュリティ・運用境界ガイド
- **サンドボックスと権限管理**:
  自社開発スクリプトが`.comp`ディレクトリを監視・書き込みする際、macOSの「フルディスクアクセス」や「ファイルとフォルダのアクセス権」の要求が発生します。配布用インストーラーにはDeveloper IDによる公的公証（Notarization）を付与するか、社内MDM（Jamf等）でスクリプトの実行権限を事前配布してください。
- **フォントライセンスの遵守**:
  バナーを自動生成する際、ローカル環境にインストールされた商用フォントが適切に埋め込み・ラスタライズ可能か確認してください。Google Fonts等のSIL Open Font Licenseを採用することを推奨します。
