## 主な機能とアーキテクチャ概要

`universal-modder`の中核機能は、以下の4つの自律モジュールに集約されます。

1. **`um scan` & 逆コンパイルエンジン**:
   実行ファイルからエンジン種別（Unity、Unreal、.NET、Native C++）、アンチチート、依存関係を瞬時に特定。ILSpyやCpp2IL、Ghidraを裏側でキックしてコード構造をマップ化。
2. **fal.ai MCP連携によるアセット生成パイプライン**:
   仕様に合わせた2Dピクセルアート、PBRテクスチャ、3Dモデル（GLB）、効果音、ボイスをREST/MCP経由で完全自動生成。
3. **`um win` 低レイヤーOS自動制御**:
   DirectInputレベルのマウス/キーボードエミュレーション、DirectX/Vulkanフレームキャプチャ、プロセス単位の排他的オーディオキャプチャ。
4. **自己増殖型ナレッジベース（Knowledge Base）**:
   AIが遭遇したバグやエンジンの落とし穴をMarkdown形式の知見として自動蓄積。次回の解析効率を指数関数的に向上。

## 🛠️ 【即時本番起動】Docker Compose & 本番設定キット

`universal-modder`をベースとしたAPI化ブリッジおよび解析環境をコンテナ上で安全に稼働させるための完全な設定ファイルです。

### 1. `docker-compose.yml`
```yaml
version: '3.8'

services:
  modder-agent:
    build:
      context: .
      dockerfile: Dockerfile
    container_name: universal-modder-core
    restart: unless-stopped
    environment:
      - FAL_KEY=${FAL_KEY}
      - ANTHROPIC_API_KEY=${ANTHROPIC_API_KEY}
      - ENV_MODE=${ENV_MODE:-production}
      - LOG_LEVEL=${LOG_LEVEL:-INFO}
    volumes:
      - ./knowledge:/app/knowledge
      - ./workspaces:/app/workspaces
      - ./output:/app/output
    ports:
      - "8000:8000"
    networks:
      - modder-net
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8000/health"]
      interval: 30s
      timeout: 10s
      retries: 3

networks:
  modder-net:
    driver: bridge
```

### 2. `Dockerfile`
```dockerfile
FROM python:3.11-slim-bookworm

# 必要なOSパッケージ（ffmpeg、git、ビルドツール）のインストール
RUN apt-get update && apt-get install -y --no-install-recommends \
    git \
    ffmpeg \
    curl \
    build-essential \
    libsecret-1-0 \
    && rm -rf /var/lib/apt/lists/*

WORKDIR /app

# uvのインストールとパス設定
COPY --from=ghcr.io/astral-sh/uv:latest /uv /bin/uv

# universal-modder CLIのインストール
RUN uv tool install git+https://github.com/rehan-remade/universal-modder

ENV PATH="/root/.local/bin:$PATH"

# 作業用ディレクトリの作成
RUN mkdir -p /app/knowledge /app/workspaces /app/output

# 簡易APIサーバー等のエントリーポイントファイル作成
COPY entrypoint.sh /app/entrypoint.sh
RUN chmod +x /app/entrypoint.sh

EXPOSE 8000
ENTRYPOINT ["/app/entrypoint.sh"]
```

### 3. `entrypoint.sh`
```bash
#!/usr/bin/env bash
set -e

echo "[+] Starting universal-modder service..."
um --help > /dev/null

# ヘルスチェック用のバックグラウンド簡易サーバー（FastAPI等に差し替え可能）
python3 -m http.server 8000 --directory /app/output &

echo "[+] Service is running on port 8000."
wait -n
```
