## 商用カスタマイズ・実装の勘所（コピペで使える設計ガイド）

### 実務でそのまま使える設定ファイルや拡張コード例

DroidDeckはKotlinで書かれたAndroidアプリと、Linuxランタイム、そしてProtonやSteamクライアントの組み合わせで動作します。カスタマイズの多くは、Androidアプリ側の設定、Linuxランタイム内のスクリプト、そしてProtonの設定ファイルで行われます。

**1. DroidDeckアプリのカスタム設定 (JSON/XML)**
DroidDeckアプリ自体はKotlinで書かれており、設定は内部的に管理されますが、外部設定ファイルで挙動を制御できる部分もあります。例えば、Steamの起動オプションやProtonのデフォルトバージョンなどを設定ファイルで管理できます。

`droiddeck_custom_config.json` (例: アプリケーションの起動オプションやUIテーマ設定)
```json
{
  "steam_launch_options": "-bigpicture -nofriendsui -nochatui",
  "proton_default_version": "GE-Proton8-25",
  "default_store_tab": "steam",
  "download_speed_tier": "high",
  "custom_ui_theme": "enterprise_dark_mode",
  "enable_analytics": false,
  "developer_mode_enabled": false
}
```
このJSONファイルをアプリの内部ストレージやSDカードの特定パスに配置し、アプリが起動時に読み込むようにカスタマイズすることで、ユーザーごとの設定や法人向けの統一設定を適用できます。

**2. Linuxランタイム内のスクリプト (Bash/Python)**
DroidDeckのLinuxランタイム内では、BashスクリプトやPythonスクリプトを使って、ゲーム起動前後の処理やシステム設定を自動化できます。

`pre_game_launch.sh` (例: ゲーム起動前にVPNを有効化するスクリプト)
```bash
#!/bin/bash
# VPNサービスを起動するコマンド (例: OpenVPNクライアント)
echo "Starting VPN service..."
/usr/bin/openvpn --config /etc/openvpn/client.conf &
sleep 5 # VPN接続確立を待つ
echo "VPN service started."
```

`post_game_exit.sh` (例: ゲーム終了後にVPNを無効化するスクリプト)
```bash
#!/bin/bash
echo "Stopping VPN service..."
killall openvpn
echo "VPN service stopped."
```
これらのスクリプトをDroidDeckのLinuxランタイム内の適切なパスに配置し、Steamのゲーム起動オプションやDroidDeckアプリのカスタム設定から呼び出すことで、高度な自動化が可能です。

**3. Protonのカスタム設定 (user_settings.py)**
Protonは、ゲームごとに詳細な設定をカスタマイズできます。これは通常、`user_settings.py`というPythonスクリプトで行われます。

`~/.steam/steam/steamapps/compatdata/<APPID>/pfx/user_settings.py` (例: 特定のゲームでDXVKのバージョンを指定)
```python
# user_settings.py for a specific game
# This file is executed by Proton before launching the game.

# Example: Force a specific DXVK version
# This might be useful for games that have issues with newer DXVK versions.
# WINE_DXVK_VERSION = "1.9.4"

# Example: Enable Proton's fsync/futex2 for better performance
# PROTON_USE_FSYNC = "1"
# PROTON_USE_FUTEX2 = "1"

# Example: Set custom environment variables for the game
# os.environ["MESA_GLSL_CACHE_DIR"] = "/path/to/custom/cache"
# os.environ["DXVK_HUD"] = "fps"

# Add any other Proton-specific settings here
```
このファイルをゲームごとにカスタマイズすることで、互換性の向上やパフォーマンスの最適化を図れます。

### 社内運用時のセキュリティ境界、アクセス権限管理、ライセンス遵守の注意点

**1. セキュリティ境界:**
*   **AndroidサンドボックスとLinuxランタイム:** DroidDeckはAndroidのサンドボックス内で`proot`を使ってLinuxランタイムを動作させます。これにより、Androidシステム全体への影響は限定的ですが、Linuxランタイム内でのセキュリティリスク（マルウェア、不正アクセス）は存在します。
*   **ユーザーデータ保護:** Steam認証情報、ゲームセーブデータ、外部ストアのAPIキーなどは機密情報です。これらがLinuxランタイム内でどのように保護されているか、またAndroidアプリとLinuxランタイム間でどのように安全にやり取りされるかを理解し、必要に応じて暗号化やアクセス制御を強化する必要があります。
*   **ネットワークセキュリティ:** ゲームダウンロードやオンラインプレイ時には、VPNの利用やファイアウォール設定など、ネットワークレベルでのセキュリティ対策を検討します。
