# 海外急上昇OSS「kev」商用化マニュアル｜社内DX提案書 ＆ 自社SaaS構築手順付き

## はじめに：なぜ今、世界中で爆発的に注目されているのか？

LLMの受託開発や社内DX推進において、いま最もクライアントや経営陣から突きつけられる相談は何かご存知でしょうか？

> **「ChatGPTでテキスト分類やルーティングを作ってみたが、たまに嘘をつく（ハルシネーション）。AIがどのくらい自信を持っているのか数値で分からないから、怖くて自動化の閾値を設定できない。あとAPI代が高すぎる」**

この課題を突きつけられた瞬間、多くの開発会社や情シス担当者は手詰まりになります。OpenAIのAPIに「確信度を1から10で答えて」とプロンプトで指示しても、出力される数値には数学的な裏付けが一切なく、完全に形骸化するからです。

これに対し、シリコンバレーのテック界隈でいま猛烈な勢いでスター数を伸ばしている（★9100超）のが、元Vercel幹部のJared Palmer氏が公開したオープンソースモデル **「kev」** です。

本OSSは、商用の超高速意思決定AI「Jev（TypeSafe System One）」のオープンソース版であり、**「Yes/No」「多肢選択」「スコアリング」の判定を、完全にキャリブレーション（較正）された『数学的確率』と共に出力する決定特化型モデル** です。

### この記事でクライアントへの受託提案の材料がそろう理由
1. **「誤判定率5%以下」を数字でコミットできる**: キャリブレーション済み確率が出るため、「確信度95%以上は完全自動処理、それ未満は人間のオペレーターへ通知」という、エンタープライズが最も欲しがる確実な自動化設計を提案できます。
2. **圧倒的なコスト削減効果（月数十万のAPI代を数千円へ）**: H100で18ms、安価なL40Sでも41ms、MシリーズMacでもローカル動作。Modalを使えば「リクエストがない時は月額0円（スケールtoゼロ）」のインフラを提供可能です。
3. **データ完全秘匿（オンプレ/プライベートVPC対応）**: 契約書、医療データ、個人情報などを一切外部API（OpenAI等）に送信せず、自社環境内だけで完結できます。

この記事では、この「kev」を武器にして **受託開発案件の提案につなげるための提案書ドラフト・見積もり構成案**、ならびに **自社で月額課金型マイクロSaaSを立ち上げるための完全実装ガイド** を網羅して提供します。

## 主な機能とアーキテクチャ概要

`kev` は、テキスト生成（自由記述チャット）を一切行いません。その代わり、与えられたドキュメント（最大65,536トークン）に対して、複数の評価基準を同時並行でスコアリングします。

```text
[入力コンテキスト (メール・契約書・ログ等)]
   │
   ├─► 質問1 (noul):   「即時エスカレーションが必要か？」 ──► 0.93 (Yesの確率 93%)
   ├─► 質問2 (choice): 「担当窓口は？」                  ──► billing (40%), returns (38%), shipping (22%)
   └─► 質問3 (score):  「顧客の怒り度合い (0〜2)」         ──► 平均スコア 1.72 (Confidence: 0.45)
```

従来の生成AIでは3回のリクエストや長いJSONプロンプトが必要でしたが、`kev` は内部のポインターヘッドにより、**1回のフォワードパス（状態キャッシュ再利用）で全問をサブ数十ミリ秒で同時に解きます**。しかも質問同士が干渉し合わない構造的隔離（Question Isolation）が施されています。

### ローカルでの動作確認（最速手順）

```bash
# クローンと依存解決
git clone https://github.com/jaredpalmer/kev.git && cd kev
uv sync --extra serve

# Kev-4Bをローカル起動 (GPUまたはApple Silicon)
uv run --extra serve python -m kev.serve --run jaredpalmer/kev-4b --port 8009
```

別シェルから以下のPythonコードを実行するだけで、すぐに精度を体感できます。

```python
from typesafe_sdk import TypeSafeClient, Noul, Choice, Score

client = TypeSafeClient(api_key="local", base_url="http://127.0.0.1:8009", model="kev-latest")

res = client.system_one(
    state="解約したいのですが、返金保証期間を1日過ぎてしまいました。なんとかなりませんか？",
    questions={
        "churn_risk": Noul(instructions="解約の意図があるか？"),
        "special_case": Noul(instructions="例外対応を検討すべき事案か？"),
        "tone": Score(instructions="顧客の感情", criteria=["穏やか", "切実", "高圧的"])
    }
)
print(f"解約リスク確率: {res.nouls['churn_risk'].noul * 100:.1f}%")
print(f"感情スコア: {res.scores['tone'].score:.2f}")
```
