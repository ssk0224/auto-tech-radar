## 主な機能とアーキテクチャ概要

`kev` は、テキスト生成（自由記述チャット）を一切行いません。その代わり、与えられたドキュメント（最大65,536トークン）に対して、複数の評価基準を同時並行でスコアリングします。

```text
[入力コンテキスト (メール・契約書・ログ等)]
   │
   ├─► 質問1 (noul):   「即時エスカレーションが必要か？」 ──► 0.93 (Yesの確率 93%)
   ├─► 質問2 (choice): 「担当窓口は？」                  ──► billing (40%), returns (38%), shipping (22%)
   └─► 質問3 (score):  「顧客の怒り度合い (0〜2)」         ──► 平均スコア 1.72 (Confidence: 0.45)
```

従来の生成AIでは3回のリクエストや長いJSONプロンプトが必要でしたが、`kev` は内部のポインターヘッドにより、**1回のフォワードパス（状態キャッシュ再利用）で全問をサブ数十ミリ秒で同時に解きます**。しかも質問同士が干渉し合わない構造的隔離（Question Isolation）が施されています。

### ローカルでの動作確認（最速手順）

```bash
# クローンと依存解決
git clone https://github.com/jaredpalmer/kev.git && cd kev
uv sync --extra serve

# Kev-4Bをローカル起動 (GPUまたはApple Silicon)
uv run --extra serve python -m kev.serve --run jaredpalmer/kev-4b --port 8009
```

別シェルから以下のPythonコードを実行するだけで、すぐに精度を体感できます。

```python
from typesafe_sdk import TypeSafeClient, Noul, Choice, Score

client = TypeSafeClient(api_key="local", base_url="http://127.0.0.1:8009", model="kev-latest")

res = client.system_one(
    state="解約したいのですが、返金保証期間を1日過ぎてしまいました。なんとかなりませんか？",
    questions={
        "churn_risk": Noul(instructions="解約の意図があるか？"),
        "special_case": Noul(instructions="例外対応を検討すべき事案か？"),
        "tone": Score(instructions="顧客の感情", criteria=["穏やか", "切実", "高圧的"])
    }
)
print(f"解約リスク確率: {res.nouls['churn_risk'].noul * 100:.1f}%")
print(f"感情スコア: {res.scores['tone'].score:.2f}")
```

## 商用カスタマイズ・実装の勘所（コピペで使える設計ガイド）

### 1. Modalを利用した本番用サーバーレスHTTPSデプロイコード
Modalを使えば、リクエストがある時だけGPU（L40S等）を起動し、アイドル時は自動で停止する「完全従量課金・維持費ゼロ」のエンドポイントが作れます。

以下のコードを `deploy_kev.py` として保存します。

```python
import os
import modal

app = modal.App("enterprise-kev-service")

# 依存関係をインストールした軽量コンテナイメージの定義
image = (
    modal.Image.debian_slim(python_version="3.13")
    .pip_install("torch", "uv", "huggingface_hub")
    .run_commands(
        "git clone https://github.com/jaredpalmer/kev.git /root/kev",
        "cd /root/kev && uv sync --extra serve"
    )
)

MODEL_NAME = "jaredpalmer/kev-4b"

@app.cls(
    gpu="L40S",
    scaledown_window=60, # 60秒アイドルでGPU停止（スケールtoゼロ）
    image=image,
    secrets=[modal.Secret.from_name("kev-api-secret")] # 事前にModalコンソールで登録
)
class KevModelServer:
    @modal.enter()
    def load_model(self):
        import subprocess
        # 内部でkev.serveプロセスをバックグラウンド起動
        self.process = subprocess.Popen([
            "uv", "run", "--extra", "serve", "python", "-m", "kev.serve",
            "--run", MODEL_NAME,
            "--port", "8009",
            "--device", "cuda"
        ], cwd="/root/kev")
        # 起動待機
        import time
        time.sleep(10)

    @modal.web_endpoint(method="POST")
    def predict(self, item: dict):
        import urllib.request
        import json

        # 認証チェック
        expected_key = os.environ.get("KEV_API_KEY")
        # リクエストヘッダー等の検証をここに追加

        req = urllib.request.Request(
            "http://127.0.0.1:8009/v1/systemone",
            data=json.dumps(item).encode("utf-8"),
            headers={"Content-Type": "application/json"}
        )
        with urllib.request.urlopen(req) as response:
            return json.loads(response.read().decode("utf-8"))
```

### 2. 自社データによるFine-tuning用JSONLデータ作成フォーマット
顧客のドメインに合わせて精度を跳ね上げるための学習データ形式です。1行1リクエストで記述します。

### 3. ファインチューニング実行コマンド（1GPUで実行可能）
Baseモデルから直接学習すると壊滅的なスコア低下を起こすため、必ず `--init_from` で公開モデルのアダプタを引き継ぎます。

```bash
uv run python -m kev.train \
    --data data/client_train.jsonl \
    --base Qwen/Qwen3.5-4B-Base \
    --init_from jaredpalmer/kev-4b \
    --epochs 2 \
    --lr 2e-5 \
    --batch 1 \
    --accum 8 \
    --dtype bf16 \
    --checkpointing 1 \
    --device cuda \
    --out runs/client-model-v1
```

### 4. セキュリティ境界とライセンス遵守の注意点
- **ネットワーク境界**: 本番運用の際は、`kev.serve` のポートを外部公開せず、リバースプロキシ（Nginx / Caddy）またはAPI Gatewayを挟んで、トークン検証（Bearer認証）とRate Limitを設定してください。
- **データプライバシー**: 顧客データを用いてFine-tuningする場合、個人情報（顧客名や電話番号）はあらかじめマスキング（擬似名化）してから学習データに投入することをSLA（サービス品質保証）として提示してください。
- **商用ライセンス**: `kev` は Apache 2.0 であり、商用利用やソースコード改変に法的な制約はほぼありません。改変したコードを自社プロプライエタリなSaaSとして非公開運用することも完全に合法です。
