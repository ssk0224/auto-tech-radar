### 2. 自社マイクロSaaS / 有料ツールとしての構築アイデア

FilmCraftの高いポータビリティ（Rustバイナリ単体で動作、WebAssembly対応、MCP完備）を活かしたSaaSアイデアを2件提案します。

- **価格設定**:
  - Starter: 月額$99（月間100レンダリングまで）
  - Growth: 月額$299（月間500レンダリング＋4K対応）
  - Enterprise: 月額$999〜（専有レンダリングキュー＋カスタムフォント）
- **技術的優位性**: FFmpegのCLIスクリプトだと字幕の折り返しやスタイル（縁取り・シャドウ）の再現が破綻しやすいが、FilmCraftのText Engine（OpenTypeシェーピング対応）によりプロクオリティの字幕レンダリングが担保される。

#### アイデアB: 「LocalCut」 - 完全プライベート・セキュア動画編集ブラウザアプリ

- **ターゲット**: 医療機関、金融機関、未公開インサイダー情報を扱うIR部門など、外部クラウドへの動画アップロードが禁止されているエンタープライズ市場。

      "args": ["mcp"],
      "env": {
        "RUST_LOG": "info"
      }
    }
  }

### 2. PythonからTCPソケット経由でFilmCraftを制御する自動化コード

FilmCraftを`filmcraft -- --control 9876`でバックグラウンド起動しておき、PythonスクリプトからJSON Linesでタイムライン配置・エフェクト付与を行うスクリプトです。

```python
import socket
import json
import time

class FilmCraftClient:
    def __init__(self, host="127.0.0.1", port=9876):
        self.host = host
        self.port = port
        self.sock = None

    def connect(self):
        self.sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
        self.sock.connect((self.host, self.port))

    def send_command(self, method: str, params: dict):
        payload = json.dumps({"method": method, "params": params}) + "\n"
        self.sock.sendall(payload.encode("utf-8"))
        response = self.sock.recv(4096).decode("utf-8")
        return json.loads(response.strip())

    def close(self):
        if self.sock:
            self.sock.close()

if __name__ == "__main__":
    client = FilmCraftClient()
    client.connect()
    
    print("Connecting to FilmCraft Engine...")

    # 1. 素材をタイムラインのV1トラックに配置 (時間単位: 254G ticks/sec)
    # 例: 開始0秒、クリップ長5秒 (5 * 254,016,000,000)
    DURATION_5_SEC = 5 * 254016000000
    place_res = client.send_command("engine.execute", {
        "command": "timeline.place",
        "params": {
            "item": 1,
            "track": "V1",
            "seconds": 0,
            "sourceIn": 0,
            "duration": DURATION_5_SEC
        }
    })
    print(f"Clip placed: {place_res}")

    # 2. Lumetriカラー補正パラメータを適用
    grade_res = client.send_command("engine.execute", {
        "command": "effects.setParam",
        "params": {
            "clip": 1,
            "effect": "lumetri",
            "param": "basic_exposure",
            "value": 0.75  # 露出を+0.75補正
        }
    })
    print(f"Grade applied: {grade_res}")

    # 3. 現在のプログラムモニターのフレームを書き出し確認
    screen_res = client.send_command("ui.screenshot", {
        "path": "/tmp/preview_frame.png"
    })
    print(f"Screenshot saved: {screen_res}")

    client.close()
```

### 3. セキュリティ境界とライセンス運用の注意点
- **ネットワーク隔離**: FilmCraftの`--control`ポートは認証機能を持たないRAWソケット通信です。本番運用時は必ず`127.0.0.1`にバインドし、外部公開する場合はリバースプロキシ（Nginx/Envoy）でmTLSまたはトークン認証を挟んでください。
- **コーデックの特許ライセンス**: 商用で大量配信を行う場合は、H.264/HEVCではなく**ProRes 422HQ（B2B納品）やAV1/VP9（Web配信）**を優先的に採用することで、MPEG特許プールの課金リスクを回避できます。
