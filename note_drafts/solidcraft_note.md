# 海外急上昇OSS「solidcraft」商用化マニュアル｜社内DX提案書 ＆ 自社SaaS構築手順付き

## はじめに：なぜ今、世界中で爆発的に注目されているのか？

いま、シリコンバレーをはじめとする世界のテックコミュニティで**GitHubスター数5,700超**を一気に獲得し、製造業エンジニアとAI開発者の双方を震撼させている超弩級OSSがあります。

それが、Pure Rust製パラメトリック3D CAD**「SolidCraft」**です。

これまで、CADの受託開発や製造業DXといえば「Autodesk Fusion 360やSolidWorksの高額ライセンスを契約し、レガシーなC++やPythonスクリプトで無理やり連携させる」か「FreeCADの重厚な環境と格闘する」しか選択肢がありませんでした。

しかしSolidCraftは、その常識を完全に破壊しました。
- **純度100%のRust実装**: メモリ安全かつ圧倒的超高速。Webブラウザ（WebGPU）でもデスクトップ同様に軽快動作。
- **ネイティブMCP（Model Context Protocol）対応**: Claude DesktopやCursorなどのAIエージェントが、**「道具」としてCADを直接操作**可能。
- **完全商用利用可能なApache-2.0 / MITライセンス**: 高額なランニングコストをゼロに。

### 💡 この記事を読めば、クライアントへの受託開発・AI導入の提案材料がそろう理由

製造業やハードウェアスタートアップは今、「CADのライセンスコスト増大」と「定型的な3Dモデリングを行う設計者不足」という深刻なペインを抱えています。

本記事では、**「自然言語で治具や筐体を自動生成する設計AIエージェント基盤」**をクライアントに提案するための材料として、提案書テンプレート・工数見積表・導入手順（Docker 構成は公式未提供の自作例・要検証）をまとめています。

## 主な機能とアーキテクチャ概要

SolidCraftは、現代のCADに必要な機能をフルセットで備えています。
- **幾何拘束スケッチ**: 同一円弧、接線、寸法駆動など完全な幾何ソルバーを独自内蔵。
- **パラメトリックタイムライン**: 過去の押し出しやフィレットの寸法を変更すれば、モデル全体が破綻なく再計算。
- **板金加工（Sheet Metal）＆ アセンブリ**: 展開図DXF出力、干渉チェック、URDF（ロボット記述形式）出力対応。
- **超高速GPUテッセレーション**: Compute Shaderを活用し、従来の50〜65倍の速度で3Dメッシュをレンダリング。
