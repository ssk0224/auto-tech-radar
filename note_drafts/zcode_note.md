ZCodeの核心は、**「Agent Harness（エージェント制御骨格）」**としての設計思想にあります。

1. **マルチモーダル・マルチサーフェス展開**:

   ReactベースのUI拡張機能（Excalidrawを用いたアーキテクチャ図の自動描画など）を動的にロード。

## 🛠️ 【即時本番起動】Docker Compose & 本番設定キット

ZCodeを単体サーバー上で即座に本番稼働させるための完全な設定ファイルです。

### 1. `docker-compose.yml`

```yaml
version: '3.8'

services:
  zcode-server:
    image: node:24-slim
    container_name: zcode-core-service
    restart: always
    working_dir: /app
    volumes:
      - ./data:/app/.zcode
      - ./workspace:/app/workspace
    environment:
      - NODE_ENV=production
      - ZCODE_DATA_BASE_DIR=/app
      - ZCODE_SERVER_WORKSPACE=/app/workspace
      - ZCODE_SERVER_AUTH_TOKEN=${ZCODE_SERVER_AUTH_TOKEN}
      - OPENAI_API_KEY=${OPENAI_API_KEY}
      - OPENAI_BASE_URL=${OPENAI_BASE_URL:-https://api.openai.com/v1}
      - ANTHROPIC_API_KEY=${ANTHROPIC_API_KEY:-}
    ports:
      - "127.0.0.1:3030:3030"
      - "127.0.0.1:5173:5173"
    command: >
      sh -c "
        apt-get update && apt-get install -y git curl python3 make g++ &&
        corepack enable && corepack prepare pnpm@10.33.2 --activate &&
        if [ ! -d '/app/.git' ]; then
          git clone https://github.com/zai-org/ZCode.git /app &&
          cd /app && pnpm bootstrap;
        fi &&
        cd /app &&
        pnpm dev:web
      "

  nginx-proxy:
    image: nginx:alpine
    container_name: zcode-nginx
    restart: always
    ports:
      - "80:80"
    volumes:
      - ./nginx.conf:/etc/nginx/conf.d/default.conf:ro
    depends_on:
      - zcode-server
```

### 2. `nginx.conf`（リバースプロキシ・WebSocket対応）

```nginx
server {
    listen 80;
    server_name _;

    client_max_body_size 100M;

    location / {
        proxy_pass http://zcode-server:5173;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    location /ws {
        proxy_pass http://zcode-server:3030;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_read_timeout 86400s;
        proxy_send_timeout 86400s;
    }

    location /api/ {
        proxy_pass http://zcode-server:3030;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

### 3. `.env.example`

```env
# 認証用ランダムトークン (32文字以上のセキュアな文字列)
ZCODE_SERVER_AUTH_TOKEN=your_super_secret_auth_token_here_generate_with_openssl

# 利用するLLMプロバイダの設定
OPENAI_API_KEY=sk-proj-xxxxxxxxxxxxxxxxxxxxxxxx
OPENAI_BASE_URL=https://api.openai.com/v1

# Anthropic Claude を利用する場合
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxxxxxxxxxx

# Azure OpenAI を利用する場合の差し替え例
# OPENAI_BASE_URL=https://your-resource.openai.azure.com/openai/deployments/your-deployment
# OPENAI_API_KEY=your_azure_api_key
```

### 起動手順
```bash
# 設定ファイルの作成
cp .env.example .env
# トークンを生成して .env に記載
openssl rand -hex 32

# 起動
docker compose up -d
```
起動後、ブラウザから `http://サーバーIP/` にアクセスすれば即座にセキュアなWebエージェントが利用可能です。

> 「その点こそが、本構成の最大のメリットです。本システムはApache 2.0ライセンスのオープンソースであり、ソースコード全文をお客様の環境内に完全にクローンして保持します。仮に上流のOSS開発コミュニティに変化があったとしても、貴社専用に固定したバージョンで永続的に稼働し続けます。また、弊社との保守契約により、セキュリティパッチの適用やプロバイダAPI仕様変更への追従は弊社が責任を持って代行いたします。」

**回答トーク**:
> 「ZCodeは裏側で業界標準の最先端モデル（Claude 3.5 SonnetやGPT-4o等）をそのまま利用するため、コード生成の知能自体はCursorやDevinと全く同等です。さらにZCodeはWeb・デスクトップ・ターミナルのすべてをサポートしており、社内Linuxサーバーへの直接アタッチなど、商用SaaSでは制限されている『現場の泥臭いインフラ作業』まで自律実行できるため、実質的な作業カバー範囲はむしろ広がります。」

### Q3. 「社内コードがLLMの学習に使われることは絶対にないと言い切れるか？」
