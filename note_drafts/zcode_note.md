# 海外急上昇OSS「ZCode」商用化マニュアル｜社内DX提案書 ＆ 自社SaaS構築手順付き

## はじめに：なぜ今、世界中で爆発的に注目されているのか？

「GitHub CopilotやCursorを使いたいが、ソースコードを海外ベンダーのクラウドに送るわけにはいかない」
「Devinのような自律型エージェントを社内専用基盤として導入したいが、月額費用が高すぎる」

エンタープライズや中堅企業の開発現場で、いま最も切実なのがこの**「AIコーディングエージェントのセキュリティと内製化」**の壁です。

この課題を完璧に突破するオープンソースとして、海外で一気に★7,800を突破したのが**「ZCode」**です。

ZCodeは、単なるチャットツールではありません。
- **Desktop（Electron）**
- **Webブラウザ（セルフホスト可能）**
- **Terminal（TUI / CLI）**

これら3つのUIを単一のコードベースから動かせる、極めて完成度の高いオープンソース・AIコーディングエージェント基盤です。

### 💡 なぜ今、この記事が受託提案の材料になるのか？
大企業やDX推進企業は、**「自社専用のセキュアなAI開発基盤」**に数百万円単位の予算を用意しています。しかし、ゼロからエージェントシステムを作るのは非現実的です。

ZCodeをセキュアなAI開発基盤のテンプレートとしてパッケージ化し、クライアントの専用VPC環境（AWS/GCP/オンプレミス）に構築・納品する提案ができます。費用の目安は、有料エリアの工数見積表で前提（人日・単価）とあわせて示しています。

本記事では、その具体的なビジネスモデル、そのまま使える提案書、見積明細、そして一発で動くDocker構成までを完全公開します。

## 主な機能とアーキテクチャ概要

ZCodeの核心は、**「Agent Harness（エージェント制御骨格）」**としての設計思想にあります。

1. **マルチモーダル・マルチサーフェス展開**: 
   開発者のローカルPCではデスクトップ版、共有開発サーバーではWeb版、CI/CDや自動化パイプラインではヘッドレスCLIを使い分け可能。
2. **Providerレイヤーの抽象化**: 
   OpenAI、Anthropic、Claudeはもちろん、社内ホストのvLLMやOllama、Azure OpenAI Private Endpointを環境変数1つで切り替え可能。
3. **UI Pluginアーキテクチャ**: 
   ReactベースのUI拡張機能（Excalidrawを用いたアーキテクチャ図の自動描画など）を動的にロード。

### クイックスタート手順（最短検証）

```bash
git clone https://github.com/zai-org/ZCode.git
cd ZCode
pnpm bootstrap
pnpm dev:web
```
上記を実行するだけで、ローカルポート `5173`（フロント）および `3030`（バックエンド）にてフル機能のWeb版エージェント環境が立ち上がります。
