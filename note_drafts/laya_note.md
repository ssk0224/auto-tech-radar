## 主な機能とアーキテクチャ概要

`laya`は、ModernBERTおよびmmBERTをベースに、厳密適格スコアリングルール（RLCD）を用いて強化学習された意思決定特化型モデルです。

1. **単一フォワードパスでの複数判定**: 1回の推論（約33ms）で、「カテゴリ分類（Choice）」「スコアリング（Score）」「確信度付きYes/No（Noul）」を同時に確定。
2. **多言語自動ルーティング**: 日本語、英語を含む100以上の言語を内蔵ルーターがサブミリ秒で判別し、最適なモデルへディスパッチ。
3. **長文サポート**: 従来の分類モデル（512トークン制限）と異なり、最大8,192トークンまで処理可能。

```python
from laya import Router

router = Router()
result = router.predict(
    "請求書が重複しています。今日中に返金されなければ解約します。",
    questions={
        "dept": {"type": "choice", "instructions": "担当部門", "criteria": {"billing": "請求", "tech": "技術"}},
        "churn": {"type": "noul", "instructions": "解約リスクがあるか"}
    }
)
# result["answers"]["dept"]["choice"] -> 'billing'
# result["answers"]["churn"]["noul"]  -> 0.982
```

## 商用カスタマイズ・実装の勘所（コピペで使える設計ガイド）

### 1. 本番用 Docker Compose & APIサーバー構成

`laya`は公式でHTTPサーバーエクストラ（`laya[serve]`）を提供しています。これを最小構成でセキュアに立ち上げる本番用設定です。

```yaml
# docker-compose.prod.yml
version: "3.8"

services:
  laya-engine:
    image: python:3.11-slim
    container_name: laya-decision-engine
    restart: always
    environment:
      - LAYA_HOST=0.0.0.0
      - LAYA_PORT=8000
      - LAYA_MODELS=multilingual,english
      - HF_HUB_CACHE=/models/cache
      - OMP_NUM_THREADS=4
    volumes:
      - ./model_cache:/models/cache
    command: >
      sh -c "pip install --no-cache-dir 'laya[serve]' &&
             laya-serve"
    ports:
      - "127.0.0.1:8000:8000" # ホスト内部からのみリッスン（リバースプロキシ配下）
    deploy:
      resources:
        limits:
          cpus: '4.0'
          memory: 4096M
        reservations:
          cpus: '2.0'
          memory: 2048M
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8000/health"]
      interval: 30s
      timeout: 5s
      retries: 3
```

### 2. TypeScript / Node.js クライアント実装（フロント/他サービス連携）

Node.jsやNext.jsバックエンドから`laya-serve`を呼び出す実務コード例です。

```typescript
// layaClient.ts
import axios from 'axios';

interface DecisionRequest {
  state: string;
  questions: Record<string, {
    type: 'choice' | 'score' | 'noul';
    instructions: string;
    criteria?: Record<string, string> | string[];
  }>;
}

interface DecisionResponse {
  routing: {
    model: string;
    detected_lang: string;
  };
  answers: {
    [key: string]: {
      choice?: string;
      score?: number;
      noul?: number; // 0.0 - 1.0 (Yesの確率)
      abstention: boolean;
    };
  };
}

export class LayaService {
  private endpoint = process.env.LAYA_ENDPOINT || 'http://127.0.0.1:8000/predict';

  async triageTicket(userTicket: string): Promise<DecisionResponse> {
    const payload: DecisionRequest = {
      state: userTicket,
      questions: {
        department: {
          type: 'choice',
          instructions: '対応すべき適切な部署を割り当ててください。',
          criteria: {
            tech_support: 'ログイン不可、バグ、機能不全',
            billing: '領収書、決済エラー、プラン変更',
            sales: '新規導入相談、見積もり希望'
          }
        },
        priority: {
          type: 'score',
          instructions: '顧客の緊急度を判定してください。',
          criteria: ['低', '中', '高（業務停止レベル）']
        },
        vip_risk: {
          type: 'noul',
          instructions: '怒りや即時解約を示唆していますか？'
        }
      }
    };

    const response = await axios.post<DecisionResponse>(this.endpoint, payload, {
      timeout: 2000,
      headers: { 'Content-Type': 'application/json' }
    });

    return response.data;
  }
}
```

### 3. 社内運用時のセキュリティ境界とライセンス遵守の注意点
- **完全閉域網での運用**: `Router`は初回起動時にHugging Face Hubからチェックポイントをダウンロードします。本番環境が完全オフライン（VPC内）の場合は、あらかじめDockerビルド時に重みをキャッシュディレクトリ（`/models/cache`）へ配置しておく必要があります。
- **Apache 2.0の遵守**: 自社SaaSに組み込む場合、ソースコードの公開義務はありません。管理画面の「OSSライセンス一覧」等にLayaの著作権表示（Copyright (c) 2026 Nandha Kishor M）とApache 2.0ライセンス全文を掲載するだけでクリアできます。
