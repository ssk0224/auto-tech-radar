## はじめに：なぜ今、世界中で爆発的に注目されているのか？

GitHubで瞬く間にスター数7,800超えを記録し、世界中のエンジニアや起業家の間で話題沸騰中のオープンソースプロジェクトがあります。それが業界特化型AIトレンド自動収集・日報生成基盤**「AIHOT」**です。

多くの企業において、競合調査や業界トレンドの収集は以下のような課題を抱えています：
- 若手社員やリサーチ担当者が、毎日1〜2時間かけてニュースサイトやSNSを巡回している
- 担当者によって情報の質にバラつきがあり、重要な法改正や技術発表を見落とす
- 海外の一次ソースをリアルタイムに翻訳・要約するノウハウがない

AIHOTは、これらの課題を**「情報源（Sources）の定義」**と**「プロンプト（Know-How）の注入」**だけで完全に自動化するソリューションです。

**なぜこの記事を読めば、クライアントに80万〜250万円の受託開発・AI導入を即提案できるのか？**
企業の経営層や事業開発部門にとって、「毎月数十時間を浪費しているリサーチ業務の完全自動化」は、ROI（投資対効果）が極めて計算しやすい領域です。AIHOTをベースにクライアント固有の業界知見を組み込み、セキュアな社内インフラへ納品するだけで、**実質工数3〜5人日程度で構築できるにもかかわらず、顧客にとっては年間数百万円の人件費削減効果をもたらすため、80万〜250万円の導入対価が容易に正当化できる**からです。

## 主な機能とアーキテクチャ概要

AIHOTが従来のスクレイピング基盤と一線を画している技術的強みは以下の3点です：

1. **独立2回スコアリングによるノイズ排除**:
   同一記事に対してプロンプトによる評価を2回独立して実施。基準に達しないPR記事や釣り記事を自動遮断。
2. **イベントクラスタリング & 熱度アルゴリズム**:
   複数のメディアが同一事件を報じた場合、自動的に1つのタイムラインイベントに集約。独立ソース数に基づき話題性をスコアリング。
3. **最新AI Agentへの標準対応**:
   人間が見るWebサイトだけでなく、MCP（Model Context Protocol）や`llms.txt`に対応。社内AI Agentが自律的に業界ニュースを引用可能。

## 🛠️ 【即時本番起動】Docker Compose & 本番設定キット

本番サーバー（Ubuntu 22.04 / 24.04 等）上でそのまま稼働する設定ファイルです。

### 1. `docker-compose.yml`
```yaml
services:
  app:
    image: node:24-alpine
    container_name: aihot-web
    working_dir: /app
    restart: always
    environment:
      - NODE_ENV=production
    env_file:
      - .env
    volumes:
      - .:/app
    ports:
      - "3000:3000"
    depends_on:
      postgres:
        condition: service_healthy
    command: sh -c "npm install && npm run build && npm run start"

  postgres:
    image: pgvector/pgvector:pg17
    container_name: aihot-db
    restart: always
    environment:
      POSTGRES_USER: ${POSTGRES_USER:-aihot_user}
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD:-aihot_secure_pass_2026}
      POSTGRES_DB: ${POSTGRES_DB:-aihot_db}
    volumes:
      - postgres_data:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U ${POSTGRES_USER:-aihot_user} -d ${POSTGRES_DB:-aihot_db}"]
      interval: 5s
      timeout: 5s
      retries: 5

volumes:
  postgres_data:
```

## 🗣️ 【成約率を最大化する】クライアントへの営業キラーフレーズ＆想定問答

### Q1. 「社内の機密情報や調査対象キーワードが外部に漏洩しませんか？」
**回答**:
> 「本システムは貴社専用の独立したプライベートクラウド環境に構築します。また、LLM呼び出しに関しても『データ学習を行わない規約（Zero Data Retention）』が明記された商用APIエンドポイントを使用するため、調査内容がAIの学習データに利用されるリスクは完全に排除されます。」

### Q2. 「AIが誤った要約（ハルシネーション）を生成するリスクはありませんか？」
**回答**:
> 「AIHOTは『独立した2回のスコアリング機構』を搭載しており、基準を満たさない低品質な情報や事実無根のテキストは自動でフィルタリングされます。さらに、画面上には必ず原文の一次ソースリンクと事実関係の抽出タグが併記されるため、ワンクリックで一次情報を確認できるダブルチェック体制を担保しています。」

### Q3. 「導入後の保守運用で自社のエンジニアリソースが取られませんか？」
**回答**:
> 「システムの動作状況、スクレイピングの健全性、LLMのコスト消費は専用の管理画面（/admin）からGUIで一括監視できます。障害時の自動再試行や予算リミット機能（ブレーカー）が標準で備わっているため、月次でのメンテナンス工数はほぼゼロで運用可能です。」
