## 主な機能とアーキテクチャ概要

Strataが12GB GPUで125Bモデルを動作させられる秘密は、独自の3階層オフロードと投機的デコーディングにあります。

1. **MoE（Mixture of Experts）最適配置**: 24,576エキスパートのうち、頻出エキスパートのみをGPU VRAM（12GB）に、全体をメインメモリ（32〜64GB）に配置し、ディスク（NVMe SSD）を巨大キャッシュテーブルとして連動。
2. **投機的デコーディング**: 小型モデルが予測したトークンを巨大モデルが一括検証することで、推論時間を1.6〜1.8倍に短縮。
3. **OpenAI / Anthropic デュアル互換API**: `http://127.0.0.1:8080/v1` で起動し、Claude Code（`ANTHROPIC_BASE_URL`）やCursorから直接呼び出し可能。
4. **マルチモーダル対応**: 画像入力（Vision）にも対応し、図面やUIスクリーンショットの解析が可能。

## 商用カスタマイズ・実装の勘所（コピペで使える設計ガイド）

商用環境で複数開発者が相乗りする場合、Strata標準の単一リクエスト処理ではキューが詰まる原因になります。NginxによるAPIキー認証とリクエストバッファリングを噛ませた本番構成が必須です。

### 1. 本番用 Nginx リバースプロキシ設定 (`nginx.conf`)
クライアント認証（Bearer Token）、タイムアウト制御、ヘルスチェックを集約します。

```nginx
events { worker_connections 1024; }

http {
    upstream strata_backend {
        server 127.0.0.1:8080;
        keepalive 32;
    }

    server {
        listen 80;
        server_name ai-local.internal;

        # クライアント認証トークンの検証
        set $valid_token 0;
        if ($http_authorization = "Bearer internal-corp-secret-key-2026") {
            set $valid_token 1;
        }

        location / {
            if ($valid_token = 0) {
                return 401 '{"error": "Unauthorized: Invalid Corp AI Token"}';
            }

            proxy_pass http://strata_backend;
            proxy_http_version 1.1;
            proxy_set_header Connection "";
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;

            # 長文生成および推論思考時のタイムアウト対策
            proxy_read_timeout 600s;
            proxy_send_timeout 600s;
            proxy_buffering off; # ストリーミング推論（SSE）を即座にクライアントへ伝送
        }

        # ヘルスチェック用エンドポイント（監視ツール連携用）
        location /health {
            proxy_pass http://strata_backend/;
            proxy_read_timeout 5s;
        }
    }
}
```

### 2. Claude Code 接続用 自動構成スクリプト (`setup-env.sh`)
社内開発者のPCで1行実行するだけで、ローカルStrataをAnthropic互換として認識させる環境変数設定スクリプトです。

```bash
#!/usr/bin/env bash
# 社内プライベートAI基盤 接続初期化スクリプト

SERVER_HOST="ai-local.internal"
CORP_TOKEN="internal-corp-secret-key-2026"

echo "Configuring Claude Code & Cursor for Private Strata Engine..."

# Anthropic API Base URL の上書き設定
export ANTHROPIC_BASE_URL="http://${SERVER_HOST}"
export ANTHROPIC_API_KEY="${CORP_TOKEN}"

# OpenAI 互換クライアント用の標準環境変数
export OPENAI_BASE_URL="http://${SERVER_HOST}/v1"
export OPENAI_API_KEY="${CORP_TOKEN}"

# 永続化（.bashrc または .zshrc への追記）
SHELL_RC="$HOME/.bashrc"
[ -f "$HOME/.zshrc" ] && SHELL_RC="$HOME/.zshrc"

if ! grep -q "ANTHROPIC_BASE_URL" "$SHELL_RC"; then
    echo "export ANTHROPIC_BASE_URL=\"http://${SERVER_HOST}\"" >> "$SHELL_RC"
    echo "export ANTHROPIC_API_KEY=\"${CORP_TOKEN}\"" >> "$SHELL_RC"
    echo "export OPENAI_BASE_URL=\"http://${SERVER_HOST}/v1\"" >> "$SHELL_RC"
    echo "export OPENAI_API_KEY=\"${CORP_TOKEN}\"" >> "$SHELL_RC"
    echo "Configuration written to $SHELL_RC"
fi

echo "SUCCESS: 接続設定が完了しました。Claude Code や Cursor から通信テストを実行してください。"
```

### 3. 社内運用時のセキュリティ境界とライセンス管理
- **ネットワーク分離**: Strataを実行するホスト端末は、社内特定サブネット（開発用VLAN）からのみ8080/80ポートへのインバウンドを許可し、外部インターネットへの不要なアウトバウンドをファイアウォールでブロックしてください。
- **ライセンス遵守**: Strataエンジン自体はMITライセンスのため完全フリーです。ただし、ダウンロードされる重みファイル（Qwen3.8-Flash-Next）の再配布やサービス利用時は、Qwenの利用規約および生成物制限条項に準拠していることを社内コンプライアンス規程に明記してください。
