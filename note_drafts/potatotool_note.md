# 海外急上昇OSS「PotatoTool」商用化マニュアル｜社内DX提案書 ＆ 自社SaaS構築手順付き

## はじめに：なぜ今、世界中で注目されているのか？
サイバーセキュリティの脅威は日々進化し、企業や組織は常に新たな攻撃手法への対応を迫られています。Webshellによるサーバー侵害、巧妙な暗号化を用いた通信、未知の脆弱性を狙った攻撃など、セキュリティ担当者の業務は複雑化の一途を辿っています。このような状況下で、複数の専門ツールを使い分け、それぞれの連携に苦労している方も少なくないでしょう。

そんな中、GitHubで1200以上のスターを獲得し、急速に注目を集めているオープンソースプロジェクトが「**PotatoTool**」です。このツールは、ネットワークセキュリティの専門家、レッドチーム・ブルーチームのメンバー、そしてセキュリティ愛好家のために設計された、**多機能な総合セキュリティツール**として登場しました。

PotatoToolの最大の魅力は、その名の通り、暗号化トラフィックの解読、情報収集、脆弱性スキャン、逆コンパイル、データ分析、さらにはAIを活用した解析まで、**セキュリティ業務に必要な多様な機能を一つのアプリケーションに統合**している点にあります。これにより、ツールの切り替えによる手間や学習コストを削減し、セキュリティ業務の劇的な効率化を実現します。JavaFXをベースとしたデスクトップアプリケーションとして、Windows、Linux、Macの主要OSで動作し、直感的な操作性も兼ね備えています。

## 主な機能とアーキテクチャ
PotatoToolは、Java 8またはJava 11+（推奨）で動作するJavaFXベースのデスクトップアプリケーションです。その豊富な機能は、大きく以下のカテゴリに分けられます。

1.  **一括解読機能**:
    *   Webshellインタラクティブトラフィック、ネットワークトラフィック、多様な暗号化方式（AES, DES, RSA, XOR, Base64, Unicode, Hex, URLなど）、強固な難読化（Unicode多u混淆、log4j強混淆など）、コンポーネント（Shiro, Log4j, JWTなど）やミドルウェア（WebLogicDB, SpringDBなど）の暗号化データを自動検出・解読します。
    *   多様な入力形式（純粋な暗号文、JSON/Form Dataリクエストボディ、完全なリクエストパケット）に対応し、Keyの爆破方式も複数サポート。
    *   AIによる悪意あるスクリプトの分析も可能です。
2.  **情報収集**:
    *   Fofa, Hunter, Quake, ZoomEye, Shodanといった主要なサイバー測量プラットフォームを統合。
    *   ドメイン、IP、企業名（中国）を対象に、スマート拡散検索、敏感情報検索、情報漏洩検索を実行し、データを集約・整理します。
    *   強力なデータクレンジング機能（重複除去、スマートなダーティデータフィルタリング）も内蔵。
3.  **AI分析**:
    *   独自のAIモデルを搭載し、質問応答や悪意あるスクリプトの分析を支援します。ChatGPTのAPIキーを設定して利用することも可能です。
4.  **その他**:
    *   **IPフィルタリング**: IPアドレスの抽出、帰属地検索、国内外/内外網分類、地域分類。
    *   **反コンパイル**: Javaコードの逆コンパイル（Idea, Procyon）。
    *   **ブロックチェーン溯源**: ウォレットアドレス、トランザクションハッシュ、ブロックIDの検索。
    *   **帰属地照会**: 銀行カード、携帯電話番号のバッチ照会。
    *   **ファイル元情報抽出**: GPS情報を含むファイルからのメタデータ抽出。
    *   **免殺**: Webshell（Godzilla, Behinder, AntSword対応）のアンチウイルス回避、偽造署名、フィッシングQRコード生成。
    *   **カスタムメモリコード**: Tomcat, SpringMVCなど主要ミドルウェア向けのメモリコード生成。
    *   **コマンド生成・照会**: リバースシェル、MSFVenom、HoaxShell、内網プロキシ、ファイルダウンロード、痕跡消去コマンドの生成。AIによるコマンド解答も。
    *   **KB提権照会**: WindowsのKB番号に基づく権限昇格脆弱性の検索。
    *   **プロセス分析**: 殺ウイルスソフトや潜在的な悪用プロセスを検出。
    *   **情報生成**: 個人情報、通信情報、組織情報、銀行カード情報の生成。

### クイックスタート手順
PotatoToolの最新バージョンV2.5は、現在プレビルドされたリリースが提供されていません。ソースコードからビルドする必要があります。

1.  **環境要件**: Java JDK 8または11+（推奨）、Maven 3.6以上。
2.  **ソースコード取得**: GitHubリポジトリからクローンします。
    `git clone https://github.com/potato-security/PotatoTool.git`
3.  **ビルド**: クローンしたディレクトリで、ターゲットJDKバージョンに合わせたMavenコマンドを実行します。
    *   JDK 11+の場合: `mvn -f jdk11+.xml clean package`
    *   生成されたjarファイルは `./outJar/` ディレクトリにあります。
4.  **起動**: 生成されたjarファイルを実行します。
    `java -jar ./outJar/PotatoTool-<バージョン>-jdk11+.jar`
    *   **起動パスワードは `potato520` です。**
    *   MacユーザーでJavaFX関連の問題が発生する場合、JavaFXコンポーネントを含むJDK（例: Azul Zulu JDK FX版）の使用を検討してください。
