## 主な機能とアーキテクチャ概要

- PotatoTool は JavaFX で作られたデスクトップのセキュリティツールで、暗号化された通信の復号・情報収集・脆弱性スキャン・逆コンパイルと、いくつかのデータ照会・分析の機能を備えます。
  - 原文（README）: PotatoTool 是一款基于 JavaFX 的桌面安全工具,包含加密流量解密、信息收集、漏洞扫描、反编译和若干数据查询与分析功能。
- レッドチームとブルーチームの画面を 1 つのアプリにまとめ、セキュリティテストや分析の作業で使えるようにしています。
  - 原文（README）: 红蓝队页面集中在同一个应用中,方便在安全测试和分析工作中调用。
- 作者は、正式に認められた企業のセキュリティ対策の範囲でだけ使うよう求め、利用時には各地の規則に合い必要な許可を得ていることの確認を求めています。
  - 原文（README）: 2、本工具仅面向合法授权的企业安全建设行为,在使用本工具进行检测时,您应确保该行为符合当地的法律法规,并且已经取得了足够的授权。
- ブルーチームの機能は WebShell の通信・エンコードと暗号文・ファイルとネットワークのデータを扱い、レッドチームの機能は情報収集・ポートと脆弱性のスキャン・コマンドやペイロードなどの補助ツールを含みます。
  - 原文（README）: 蓝队功能主要处理 WebShell 流量、编码与密文、文件和网络数据;红队功能包括信息收集、端口与漏洞扫描,以及命令、载荷等辅助工具。
- プロジェクトは改良が続いており、一部の機能は POC の形式・対象の環境・外部インターフェースの割り当て・手元の Java の実行環境に左右されます。
  - 原文（README）: 项目仍在迭代,部分能力会受到 POC 格式、目标环境、外部接口配额和本地 Java 运行环境的影响。
- Windows・Linux・Mac で動作します。
  - 原文（README）: 兼容平台 / 支持 Windows、Linux 和 Mac 操作系统
- 現在、V2.5 のビルド済み Release はなく、使うにはソースを取得して自分でビルドします。
  - 原文（README）: 目前暂未提供 V2.5 的预打包 Release;需要使用当前版本时,请获取源码并按“从源码构建”一节自行构建和打包。
